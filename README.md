## 1. 🏠 [Room Type Predictor – NYC Airbnb](https://github.com/vijayrjs2019/AI-ML-Project/tree/main/Room%20Type%20Predictor%20%C2%B7%20NYC%20Airbnb)

### 📌 Project Overview

**Room Type Predictor – NYC Airbnb** is a Machine Learning classification project designed to predict Airbnb room types in New York City based on property details, pricing, location, availability, and other relevant features.

The project uses the NYC Airbnb dataset to analyze property listings, identify patterns, and build predictive models that classify listings into different room types, such as Entire Home/Apt, Private Room, and Shared Room.

## 2. 🧠 [Mental Health Score (Mansik Santulan Score)](https://github.com/vijayrjs2019/AI-ML-Project/tree/main/Mansik%20Santulan%20Score)

### 📌 Project Overview

**Mental Health Score (Mansik Santulan Score)** is a Machine Learning-based project designed to assess mental well-being by analyzing relevant input parameters and generating an indicative mental health score.

The project focuses on using data analysis and Machine Learning techniques to understand patterns in mental well-being and provide a data-driven score prediction.
