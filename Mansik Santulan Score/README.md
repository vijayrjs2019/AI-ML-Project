## 💻 Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/vijayrjs2019/AI-ML-Project.git
```

**2. Navigate to the project directory**

```bash
cd AI-ML-Project
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate virtual environment (Windows)**

```bash
venv\Scripts\activate
```

**5. Install dependencies**

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter streamlit
```

## ▶️ Run Jupyter Notebook

```bash
jupyter notebook
```

## ▶️ Run Streamlit Application

Navigate to the relevant project directory and execute:

```bash
streamlit run app.py
```
